Three Ways

To Turn It Off

Thinking mode is controllable — just not from the extension yet

01

One-off, from the CLI

Good for a quick check, lasts for that session only.

ollama run qwen3 --nothink

02

Per API request

What any tool or script hitting the API can set itself.

{ "model": "qwen3",
  "think": false }

03

Baked into a Modelfile

A permanent variant your editor can point at.

FROM qwen3
PARAMETER nothink true

Option 3 is the best fit for a team; ollama create qwen3-fast -f Modelfile gives everyone a permanent "fast" variant the VS Code connector can point to, with no flags to remember.

The Modelfile route is the one that scales to a team — everyone points at the same variant instead of each person remembering a flag. Options 1 and 2 are fine for trying it out or for a script.
