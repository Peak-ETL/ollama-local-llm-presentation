What it is

An open-source, cross-platform runtime for running open-weight models on your own hardware. It wraps llama.cpp and handles downloading, quantizing, and loading models so you don't hand-configure any of that.

How it works

ollama run <model> pulls a pre-quantized model and starts an OpenAI-compatible REST API in the background on localhost:11434

Why use it over raw llama.cpp

One command to install, pull, and serve, plus a model library, Modelfiles, and the API surface editor and agent integrations expect. It's built for a desktop or server — for true edge devices, you'd reach for llama.cpp directly.

Quick level-set before we get into why local, our setup, and the models — Ollama is the "Docker for LLMs" comparison people reach for: it doesn't invent a new inference engine, it packages one (llama.cpp) with a good CLI, a model registry, and a standard API. The pyramid reads bottom-up: your hardware is the foundation, llama.cpp sits on it, Ollama packages that, and your editor rides on top.
