Chat and agents are the real spend

Autocomplete stays cheap to give away; small prompt, short completion, tight context. Chat and multi-step agent tool calls are where large context windows and repeated file re-reads run up the bill.

Local inference is free per token

Once a model is downloaded, running it costs electricity, not API credits; no per-token bill for exploratory chat or agentic loops.

My angle

Free tokens for everyday chat and exploratory work, learning where free and near-free tiers fall short and putting a GPU I'm not using for games or anything else to work.
