Rough edges worth knowing about up front

No thinking toggle in the UI

It's a CLI flag, an API parameter, or a custom Modelfile, not a setting in the VS Code connector.

Switching models isn't free

Swapping mid-session means unloading one model and loading the next.

VRAM is the real budget

The jump from a 7B to a 30B model is real.

Not every model is local

Ollama also offers hosted models. Pull one whose name ends in :cloud and the prompt runs on their servers, not your GPU.

There are real trade-offs when using a local LLM

Keep the tone matter-of-fact here; a list of rough edges buys credibility for everything claimed earlier. On the last card: Ollama now serves hosted models through the same localhost address as local ones — the only difference is the model name (a :cloud suffix) and being signed in. So "I called localhost" does not prove the work happened on your machine; the model tag is what decides. Matters for the privacy argument earlier.
